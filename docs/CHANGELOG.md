# 1.0.1 — 2026-10-06

针对 OnePlus PLZ110 / Android 17 实机反馈：Wi-Fi 为 192.168.104.11，网关 192.168.104.1，7676 / 7788 TCP 连接超时。该日志尚不能区分相机模式、连接确认、组播过滤或固件握手差异。

- 增加 UDP 1900 多播公告监听，并保留临时端口的搜索回复接收。
- 从临时和固定端口发送三星 SSDP 搜索，补充当前网关的单播搜索；约 45 秒内持续发现，并轮询重试描述服务；不要求相机出现“允许”弹窗。
- 延迟到达的 LOCATION 会参与连接；不会因为先前已有手动地址而提前结束发现。
- 记录 Android 本地网络授权、所选网络 / 接口、默认网络、发现发送与回复 / 公告及结束统计，区分“没收到报文”和“描述服务不可用”。
- 增加 6 项真实本地 UDP 回归测试。保留包名、原签名、源码、版本历史和导入索引，versionCode 从 1 增至 2。

此版修正发现流程的已知缺口，仍需用户 WB800F 验证，不将这些修改宣称为已确定的实机故障原因。
