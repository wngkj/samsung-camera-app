# 1.0.2 — 2026-10-06

用户的 1.0.1 日志确认本地网络权限已允许，192.168.104.11 / 网关 192.168.104.1 上 DLNA 端口仍超时。核验旧三星客户端后发现：104 子网对应相机选片发送，使用 SP 而非 DLNA。这是前两版缺失的协议分支。

- 自动识别 192.168.104.*，建立 HEAD /sp/control（8100–8103）会话，手机监听 18100，支持在相机选 JPEG 照片并共享 / 发送。
- 100 Continue 之后接收原始文件；完整写入 MediaStore 后才发送 200 / Sub-ErrorCode: 0。失败 / 取消清理 pending；已完成照片保留。
- 按完整文件 SHA256 去重，重复文件接收后成功应答但不重复保存。仅接收当前相机 IP 的连接。
- 接收会话使用前台服务，支持停止接收；更新界面和帮助，保留手机选片 DLNA 功能。
- 可选填手机当前 Wi-Fi MAC 作为兼容标识，拒绝把手机自身 IP 作为相机地址。
- 增加 12 项真实 TCP 接收 / 握手测试；37 项协议测试通过。包名 / 升级签名保持，versionCode 增为 3。

新版 SP 流程仍需 WB800F 实机确认；不将本地模拟测试描述成相机实测成功。

# 1.0.1 — 2026-10-06

针对 OnePlus PLZ110 / Android 17 实机反馈：Wi-Fi 为 192.168.104.11，网关 192.168.104.1，7676 / 7788 TCP 连接超时。该日志尚不能区分相机模式、连接确认、组播过滤或固件握手差异。

- 增加 UDP 1900 多播公告监听，并保留临时端口的搜索回复接收。
- 从临时和固定端口发送三星 SSDP 搜索，补充当前网关的单播搜索；约 45 秒内持续发现，并轮询重试描述服务；不要求相机出现“允许”弹窗。
- 延迟到达的 LOCATION 会参与连接；不会因为先前已有手动地址而提前结束发现。
- 记录 Android 本地网络授权、所选网络 / 接口、默认网络、发现发送与回复 / 公告及结束统计，区分“没收到报文”和“描述服务不可用”。
- 增加 6 项真实本地 UDP 回归测试。保留包名、原签名、源码、版本历史和导入索引，versionCode 从 1 增至 2。

此版修正发现流程的已知缺口，仍需用户 WB800F 验证，不将这些修改宣称为已确定的实机故障原因。
