# 安装包及公开源码下载

所有 APK 都是此前交付的原签名文件，未重新构建或更换签名。
三个公开源码 ZIP 已逐版本移除私钥和实际密码。

- [v1.0.2](v1.0.2/)：当前版本，补齐相机选片发送的 SP 接收路径。
- [v1.0.1](v1.0.1/)：持续发现和网络诊断。
- [v1.0.0](v1.0.0/)：初始手机选片版本。

下载时打开对应版本的文件，使用 GitHub 的 Download raw file 按钮；也可从各版本 Release 页的直链下载。
每个目录提供 SHA256SUMS；v1.0.2 的 public-history.bundle 是清理后的三个版本 Git 历史。

由于本次环境访问 GitHub Release 附件上传接口时持续返回 Bad Content-Length，下载文件保存于本仓库，并由 Release 页面链接到固定提交中的文件。
